# PranaFlow • Classical Yoga & Mindful Living SaaS Platform 🧘🌿

A modern, high-conversion Classical Yoga SaaS web platform combining ancient lineage traditions with mindful software architecture. Designed with a calming earth-and-forest aesthetic (forest greens, warm cream parchment, and sandalwood tones), interactive wellness tools, and dedicated clinical specialty pages.

---

## 🌟 Key Platform Features

* **SaaS Design Language**: Clean glassmorphic navigation, sticky headers, segmented pill links, badge indicators, and interactive micro-interactions.
* **100% Zero-Dead Buttons**: Every button on the platform triggers a modal syllabus inspector, interactive practice tool, or audio player.
* **Interactive Wellness Suite**:
  * **Cyclic 4-7-8 Breathwork Pacer**: Real-time visual breath dilation with sound bowls and soothing interval pacing.
  * **Interactive Course Finder**: 3-step recommendation engine matching practice duration, style, and goals to personalized sadhanas.
  * **Himalayan Singing Bowl Sound Engine**: Synthesized sacred acoustic frequencies (including Heart Chakra F-tone for labor calm) using Web Audio API.
  * **Daily Sadhana Progress Tracker**: Live checklist with percentage calculation and completion toasts.

## 🚀 Deployment & Local Setup

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/kyadaritarun/yoga.git
   cd yoga
   ```

2. **Open in Browser**:
   * Simply double-click `index.html` or open via VS Code Live Server.

3. **Deploy via GitHub Pages**:
   * Go to **Settings > Pages** on your GitHub repository.
   * Under **Branch**, select `main` and root `/`.
   * Click **Save** — your site will be live at `https://kyadaritarun.github.io/yoga/`.
